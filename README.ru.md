# dsh-novel-forge — универсальный AI-инструмент для творчества на DeepSeek Harness (обёртка в виде навыка/способности)

> **🌐 Языки** — [简体中文](README.md) · [English](README.en.md) · [Français](README.fr.md) · Русский · [Español](README.es.md) · [Português](README.pt.md)
> Обновления: см. [CHANGELOG](CHANGELOG.md)

> Превращает «织文 NovelForge» в **универсальную творческую оболочку DeepSeek Harness (multi-capability studio)**:
> в одной сессии выполняется **создание романа / имитация · продолжение · переписывание текста / написание резолюции Совбеза ООН / редактирование академических писем-обращений**, с поддержкой **многоязычного письма**.

Движок оформляется как Harness **бандл-плагин**, принцип работы:
**всё творчество выполняется в сессии/рабочей области harness** — модель определяет намерение и напрямую вызывает инструменты (для романа — `novel_forge_*`,
для контента/документов/писем — `novel_forge_cap_*`), результаты и превью текста возвращаются в сессию. **Не нужно открывать ни один браузер**;
встроенное веб-приложение служит лишь опциональным визуальным интерфейсом (инструменты и веб-страница используют одни и те же данные и синхронизируются между собой).

### Предоставляемые «способности» (capabilities)

В движке есть реестр способностей `capabilities.js`; при создании проекта задаётся `cap`, разные способности используют единый движок генерации/применения:

| Способность `cap` | Название | Описание | Действия генерации |
|---|---|---|---|
| `novel` | Создание романа | идея→сеттинг→персонажи→план→построчное написание→вычитка→экспорт (по умолчанию) | `idea/bible/characters/outline/chapter/audit_*` |
| `content` | Текстовый контент | загрузить исходник → анализ → имитация / продолжение / переписывание | `content_analyze / content_imitate / content_continue / content_rewrite` |
| `doc` | Стиль официального документа | написание резолюции Совета Безопасности ООН | `doc_resolution` |
| `email` | Академическая коммуникация | редактирование академических писем-обращений | `email_cold` |

**Многоязычность**: проекту можно задать `language` (zh/en/fr/ru/es/pt или любой язык); движок внедряет требование к целевому языку в инструкции по написанию;
фронтенд-интерфейс содержит селектор языка (верхняя панель) с поддержкой кит./англ./фр./рус./исп./порт. (непереведённые языки откатываются к китайскому).

### Установка (один из трёх способов)

Когда доступен CLI `dsh` (внутри исходного checkout — `pnpm dsh`):

```sh
# 1) Установить напрямую из локальной папки (рекомендуется для отладки)
dsh plugin add F:\typing\novel-forge-plugin

# 2) Упаковать в tarball для распространения (без прав на сборку)
pnpm pack   # получим dsh-novel-forge-0.3.0.tgz
dsh plugin add ./dsh-novel-forge-0.3.0.tgz

# 3) Или сразу опробовать как overlay через --patch (без открытия profile)
dsh --patch F:\typing\novel-forge-plugin\cordis.patch.yml --patch-argv
```

> Если pnpm ≥10 требует авторизации скриптов сборки для git-зависимостей: в этом пакете нет скриптов сборки, достаточно распространять исходники как есть.

### Предоставляемые сервисы

| Член | Описание |
|---|---|
| `ctx.novelForge.url` | Адрес доступа после готовности (например, http://127.0.0.1:54321) |
| `ctx.novelForge.status` | `running` / `stopped` |
| `ctx.novelForge.start()` | Ручной запуск (автоматически выбирает свободный порт, ожидает прохождения проверки работоспособности) |
| `ctx.novelForge.stop()` | Остановить дочерний процесс |
| `ctx.novelForge.describe()` | Информация о приложении и последние логи |
| `ctx.novelForge.capabilities()` | Список способностей (novel/content/doc/email и действий) |

### Инструменты сессии для романа (novel_forge_*, всего 12)

Хост-агент вызывает их автоматически при обнаружении намерения создать роман; **вся работа выполняется в сессии, браузер открывать не нужно**.

| Инструмент | Назначение |
|---|---|
| `novel_forge_status` | Статус движка + список проектов (обычно первый шаг) |
| `novel_forge_new_project` | Создать новое произведение (возвращает projectId) |
| `novel_forge_seed_idea` | Записать идею пользователя в карточку идеи |
| `novel_forge_ideate` | Мозговой штурм AI с кандидатными идеями (после выбора — seed) |
| `novel_forge_develop_project` | Продвижение по фазам: flesh/world/characters/outline/audit (перезапись требует подтверждения) |
| `novel_forge_read_project` | Чтение прогресса/плана/персонажей/**текста главы** для чтения и принятия решений в сессии |
| `novel_forge_write_chapter` | Написать текст N-й главы и автоматически заархивировать в память (возвращает превью текста; уже написанную главу нужно подтвердить) |
| `novel_forge_edit_chapter` | Доработка написанной главы: rewrite переписать / polish отшлифовать / continue продолжить / summarize заархивировать |
| `novel_forge_extend_outline` | Добавить в план N глав (автоматическое расширение глав при продолжении длинного произведения) |
| `novel_forge_chain` | Без контроля: full=дописать до полного текста / write=написать оставшиеся главы |
| `novel_forge_export` | Экспорт в md/manuscript/txt/json, **полный текст возвращается прямо в сессию** (может обрезаться) |
| `novel_forge_remove_project` | Удалить проект (нужно подтверждение пользователя) |

### Инструменты диалога для способностей (capability_*, новые)

Обрабатывают текстовую работу за пределами романов. Всё выполняется в сессии.

| Инструмент | Назначение |
|---|---|
| `novel_forge_capabilities` | Перечислить доступные способности и действия |
| `novel_forge_cap_create` | Создать проект способности (cap=content/doc/email, можно указать language) |
| `novel_forge_cap_set_source` | Записать исходный текст/черновик/тему и параметры |
| `novel_forge_cap_analyze` | Проанализировать исходный текст (тема/стиль/структура/персонажи/тема) |
| `novel_forge_cap_run` | Выполнить imitate/continue/rewrite/doc/email, вернуть превью |
| `novel_forge_cap_read` | Прочитать обзор проекта / исходный текст / список результатов (можно указать index для полного просмотра) |

Результаты всех инструментов несут семантику `ok/code/error` (например, `NEED_CONFIRM`), на основе которой модель запрашивает подтверждение у пользователя и не перезаписывает молча уже созданный контент.

### Настраиваемые параметры (cordis.patch.yml → config)

- `port`: фиксированный порт; `0` = авто-выбор свободного порта (по умолчанию)
- `host`: по умолчанию `127.0.0.1` (данные/ключи только на этом компьютере; для доступа по локальной сети поменяйте на `0.0.0.0` на свой риск)
- `autoStart`: автозапуск после старта хоста (по умолчанию `true`)
- `startTimeoutMs`: тайм-аут проверки работоспособности (по умолчанию 20000)
- `dataDir`: каталог данных (относительно `app/` или абсолютный путь; по умолчанию `app/data`, изолирован от хоста и персистируется вместе с пакетом)

### Требования к окружению и примечания

- На хост-машине должен быть доступен **Node ≥ 18.17** (плагин запускает безголовый движок-подпроцесс через текущий исполняемый файл `node`).
- Форма использования: **сессия harness и есть основной интерфейс**; веб-интерфейс по адресу `ctx.novelForge.url` — лишь опциональный визуальный редактор,
  использующий те же данные, что и инструменты, его можно открыть в любой момент для сверки, но **он не является обязательным условием использования**.
- При первом запуске автоматически создаются встроенный пример роман «Письмо из туманного порта» и пресеты 12 вендоров моделей (включая офлайн-эмулятор движка, позволяющий пройти весь процесс без Key).
- Ключи API моделей хранятся открытым текстом в `app/data/settings.json` (для личного локального использования; не разворачивайте в недоверенной среде).
